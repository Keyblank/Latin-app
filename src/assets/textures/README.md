# Texture della città

Metti qui le immagini per sostituire le texture generate dal codice.
Vengono raccolte automaticamente: **basta il nome giusto**.

| File | Superficie |
|---|---|
| `roof.jpg` | tegole dei tetti |
| `plaster.jpg` | intonaco dei muri |
| `ashlar.jpg` | muratura in blocchi (mura, torri, basamenti) |
| `marble.jpg` | colonne e trabeazioni |
| `grass.jpg` | prato dell'isola |
| `paving.jpg` | basolato delle vie |
| `dirt.jpg` | terra battuta (sentieri e fianco dell'isola) |

Per il rilievo, aggiungi (facoltativo) la mappa normale con lo stesso nome
e il suffisso `-normal`, es. `roof-normal.jpg`.

**Requisiti**
- **Seamless** (senza cuciture): devono ripetersi senza stacchi
- Quadrate, **512 o 1024 px**
- **JPG** (più leggero), qualità ~80
- Licenza libera: [ambientCG](https://ambientcg.com) e
  [Poly Haven](https://polyhaven.com/textures) sono CC0

Se un file manca, resta la texture generata dal codice: si possono
sostituire una alla volta.
